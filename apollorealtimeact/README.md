# Apollo in Real Time Website Walkthrough

This folder contains a short video walkthrough of my interaction with the **Apollo in Real Time** website for the Apollo 17 assignment.

## Purpose

The purpose of this video is to document that I explored the Apollo 17 mission interface and became familiar with the synchronized mission materials, including:

- Mission timeline
- Audio recordings
- Transcript
- Video panels
- Still images
- Mission status information
- Mission milestone controls

## Website Used

The walkthrough was recorded using the Apollo 17 section of Apollo in Real Time:

https://apolloinrealtime.org/17/

## Assignment Context

This video supports **Prompts 1--3** of the assignment. These prompts require entering the Apollo 17 interface, exploring the timeline, and becoming familiar with the mission data panels before beginning the written analysis.

The written responses in the assignment begin with **Prompt 4**, where observations, reflections, and comparisons are required.

## File Description

The video in this folder shows me navigating the Apollo in Real Time website, exploring the Apollo 17 interface, and demonstrating how the timeline, transcript, audio, video, and images are connected to the mission sequence.

## Note

This video is included as supporting evidence for the assignment and is not intended to replace the written responses.
